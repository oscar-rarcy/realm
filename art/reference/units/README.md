# Realm Unit Reference Library

This folder contains curated unit reference images supplied by the user.

These images are **reference-only**. They show the kind of gear, equipment, weapon tier, armour tier, shield placement, horse tack, and front/back read needed for Realm unit generation. They are not final game sprites, not runtime assets, and not the visual style target for the game.

When using these images with image generation:

- Use them as equipment and silhouette references only.
- Redraw the result as stylized Realm small-RTS sprite art.
- Do not copy the source image's exact pixels, finish, lighting, proportions, pose, background, or style.
- Keep the generated prompt's direction, team-colour slots, state grid, and production contract authoritative.
- Keep output candidates under `art/tiles/candidates/` and promote accepted runtime-ready files only under `assets/tiles/`.

Current coverage is focused on human/player units and equipment tiers. Siege units and ships do not yet have curated front/back references here.
